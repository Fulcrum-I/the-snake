# Изгиб Питона

Классическая игра «Змейка», разработанная на Python с использованием библиотеки Pygame.

## Возможности
- Управление змейкой с помощью стрелок.
- Увеличение длины после поедания яблок.
- Проход через границы игрового поля.
- Перезапуск после столкновения с собственным телом.

## Установка и запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите игру:

```bash
python the_snake.py
```

## Управление

Используйте клавиши ↑ ↓ ← → для изменения направления движения змейки.
